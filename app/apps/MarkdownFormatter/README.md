# Markdown Formatter

## Features


- General formatting.
  - Make indent 4-spaces.
  - Remove trailing spaces.
  - Remove extra space after list and heading.
  - Remove extra blank lines.
- Auto fix.
  - Re-Assign number Ordered list
  - Convert url in text to markdown link.
  - Convert image url in text to markdown image.
  - Add/remove space for broken inlines
  - And more.
